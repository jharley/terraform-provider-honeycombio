# Ephemeral Resource: honeycombio_api_key

Creates a short-lived Honeycomb API Key. The key is deleted when the Terraform operation completes. The key secret is never stored in Terraform state.

For more information about API Keys, check out [Best Practices for API Keys](https://docs.honeycomb.io/get-started/best-practices/api-keys/).

-> This resource requires the provider be configured with a Management Key with `api-keys:write` in the configured scopes.

## Example Usage

```terraform
ephemeral "honeycombio_api_key" "example" {
  name = "ephemeral config key"
  type = "configuration"

  environment_id = var.environment_id

  permissions {
    create_datasets = true
    run_queries     = true
  }
}
```
